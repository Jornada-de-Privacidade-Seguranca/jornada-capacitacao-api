# Journey criterion scores

Taiga story: [#115 — Expor pontuação agregada por critério no resultado da jornada](https://tree.taiga.io/project/jotaf-dashboard/us/115) (internal ID `9642784`).

The completed journey detail should expose the weighted contributions for professional experience, English proficiency, education, professional certifications, and competencies. Their decimal values must add up to the persisted final score. Ongoing journeys omit this breakdown.
